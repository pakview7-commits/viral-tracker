# 🔥 Viral Accounts Tracker

Personal dashboard — viral TikTok accounts (manual curation) + YouTube Shorts → TikTok gaps.

- **Site:** GitHub Pages (link repo Settings → Pages me milega)
- **Daily refresh:** `.github/workflows/daily-refresh.yml` roz subah `youtube_gap.py` chalata hai
  (YouTube viral shorts + new accounts, needs `YT_API_KEY` repo secret)
- **Tabs:** 📈 Viral Accounts (tumhare qualified accounts) • 🔥 TikTok Finder (niche-wise TikTok search)
  • 🎬 YT Shorts Gap (sirf TRUE gaps — jo TikTok par nahi hain)
- Criteria: 1-2 month me grow • no blue tick • ~10k followers • views completed • halal only

Manual "run workflow" ke liye: Actions tab → "Daily YouTube gap refresh" → Run workflow.
