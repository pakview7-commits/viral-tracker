# 🔥 Viral Accounts Tracker

Personal dashboard — viral TikTok accounts + country-wise viral topics (Germany, USA, UK, Pakistan).

- **Site:** GitHub Pages (link repo Settings → Pages me milega)
- **Daily refresh:** `.github/workflows/daily-refresh.yml` roz subah `update_trends.py` chalata hai
- Har country me ~20 different niches, har topic par ©️ copyright safety rating

Manual "run workflow" ke liye: Actions tab → "Daily trends refresh" → Run workflow.
